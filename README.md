# PriceKhoj V1

A frontend prototype for a price comparison website concept.

## Included
- Responsive home page
- Search
- Category filters
- Product cards
- Amazon / Flipkart / Meesho comparison
- Best price highlight
- Dark mode
- Price history / alert placeholders
- Mobile-friendly UI

## Important
The product prices in this version are DEMO DATA. They are not live prices.

Next development stages:
1. Backend + database
2. Approved/official product-data integrations
3. Affiliate links
4. Real price history
5. User accounts and price alerts
6. Admin dashboard
